## 📌 Overview
**AI Overview & GEO Optimizer** is an advanced AI Agent skill engineered to help SEO specialists, content strategists, and webmasters rank content inside **Google AI Overviews, Perplexity AI, and ChatGPT Search**. 

By applying cutting-edge **Generative Engine Optimization (GEO)** and **Answer Engine Optimization (AEO)** frameworks, this skill transforms traditional articles into direct AI-extractable answer sources.

---

## 🔥 Key Features & Capabilities
- **Direct Answer Block Structuring**: Optimizes headers and paragraphs to trigger AI Overview carousel and text snapshot citations.
- **Topical Citation & Fact Entity Injector**: Embeds authoritative data points, semantic entities, and references to improve information gain scores.
- **Valid JSON-LD Schema Generation**: Automatically constructs valid FAQPage, Article, and HowTo JSON-LD schema markup.
- **Information Gain & EEAT Score Audit**: Evaluates content uniqueness and credibility against search quality rater guidelines.
